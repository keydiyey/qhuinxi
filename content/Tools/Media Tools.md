### > Media Converters
- [HandBrake: Open Source Video Transcoder](https://handbrake.fr/) Open source video converter
- [Online Convert](https://image.online-convert.com/) Free online image converter
### > Image Editor
- **[PhotoPea](https://www.photopea.com/)** General Editing (Adobe but Free)
- **[GIMP](https://www.gimp.org/)** Free & Open Source Image Editor
- **[Remove Background](https://www.photopea.com/)** Removes background of images
- **[Annotately](https://www.gimp.org/)** Web based screenshot annotation and markup tool.

### > Gif Editor 
- [Ezgif](https://ezgif.com/) Online GIF maker and toolset for basic animated GIF editing. Create, edit and convert GIF, APNG, WebP and AVIF animations.
