# Removing Ads using Block The Spot (Windows)

1. Download [BlockTheSpot](https://github.com/Nuzair46/BlockTheSpot-Installer) 
2. Run the installer.
3. Check `Update or reinstall Spotify before patching` so that it can uninstall the existing spotify if ever it came from Windows Store.
4. Install the patch.

# Patching Spotify Using Spicetify (Windows)

>Visit [Spicetify](https://spicetify.app/docs/getting-started) for the whole documentation.

1. Press win + x, and run Powershell / Terminal.
2. For windows, paste the following code and hit enter
```cmd
iwr -useb https://raw.githubusercontent.com/spicetify/cli/main/install.ps1 | iex
```
3. Enter Y or Yes on every question.
4. Once installation is done, Spotify will start.
5. Click on the pushcart icon beside the search bar to open the marketplace for addons, themes, and css snippets.
6. Download whatever you want.
