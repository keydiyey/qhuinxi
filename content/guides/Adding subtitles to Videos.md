## Using MKVToolNix

For **softcoding** subtitles, I think **mkvtoolnix** is faster than **handbrake** since it does not reencode the whole thing.

1. Install **mkvtoolnix** if you haven't.

	![MKVtoolNix Setup](https://mkvtoolnix.org/wp-content/uploads/2024/10/wa_FP-mkvtoolnix_64bit_f1c6694b1eb8d05428631286742.png)
		
2. Add the video and srt files as source
	(image)
3. Rename output file (*optional*)
4. Start Encode
